# HOKKAIDO 未来リーダーズ 2026 ─ 静的サイト

インタビューメディアの静的サイト。ビルドツールなしの HTML / CSS / JavaScript のみで動きます。

> **掲載内容について**
> 現在入っている人物・記事・写真は、レイアウト確認のために別サイト（OKAYAMA FUTURE VOICE）の
> 実データを流し込んだ**デモ用の中身**です。デザインは北海道版のままなので、
> ブランドと掲載内容が一致していません。差し替え前提でご覧ください。

---

## ファイル構成

```
.
├── index.html              トップページ
├── article.html            記事ページ（1 枚のテンプレート）
├── policy.html             プライバシーポリシー
├── contact.html            お問い合わせ
├── README.md               このファイル
└── assets/
    ├── css/style.css       全ページ共通。FLOCSS
    ├── js/data.js          掲載者データ（ここを書き換えると記事が変わる）
    ├── js/article.js       記事ページのレンダラー
    ├── js/site.js          全ページ共通の動き
    └── img/
        ├── logo*.png           ロゴ各種
        ├── rule_*.png          手描き罫線（CSS に data URI で埋め込み済み）
        └── people/<slug>/      掲載者の写真
```

## 記事ページの仕組み

記事は HTML を人数分作らず、**1 枚のテンプレート + データ**で動かしています。

- `article.html?id=<slug>` を開くと、`assets/js/data.js` の該当データを
  `assets/js/article.js` が組み立てて描画します
- 掲載者を追加・修正するときは `data.js` の配列を編集するだけです
  （前後ナビ・トップのリンクも配列順から自動で決まります）
- トップページのカードと INDEX 一覧は現状 `index.html` に直接書いています

### data.js の項目

| キー | 内容 |
| --- | --- |
| `slug` | URL の `?id=` に使う識別子 |
| `catch` | 記事のキャッチコピー |
| `en` / `jp` | 英字名 / 和名 |
| `co` / `coEn` / `role` | 会社名 / 英語表記 / 役職 |
| `site` | 会社サイト URL（空なら「公式サイトを見る」を出さない） |
| `lead` | プロフィール（`\n` で改行） |
| `face` / `bg` | ヒーローの人物写真 / 背景写真 |
| `sections` | 章。`paras` の `q:1` が質問行。`photo` は 1・3 章目のみ使用 |
| `strip` | 2 章目のあとに流す写真 |

## 動き（assets/js/site.js）

- ページの出入り（開いた直後の黒が薄くなる／サイト内リンクは黒に戻してから移動）
- 画面左右を縦に流れるロゴタイプ
- ヒーローを白黒で横に流れる人物写真
- スクロール連動のフェードイン（上へ / 左から / ワイプ / ポップ）
- ヘッダーの縮小、上端のスクロール進捗バー
- 記事ヒーロー背景の視差スクロール
- イントロのコピーを 1 文字ずつ出すタイプライター
- ヒーローとイントロのスクロールスナップ
- 写真のホバー（持ち上げ + 斜めの光）
- 全面のざらつき

スマホ（680px 以下）のメニューも `site.js` が組み立てます。
ヘッダーのナビを複製した全画面パネルを `<body>` 直下に置く方式です
（ヘッダーは `backdrop-filter` を持つため、中に入れると画面全体を覆えません）。

`prefers-reduced-motion` 指定時はいずれも停止します。

## デザインの下地

- ロゴの荒々しい質感を、見出しの輪郭（SVG フィルター `#rough` / `#rough-s`）と
  罫線（ロゴ素材 `rule_*.png` を mask として使用）で全体に展開しています
- ボタンは 1 か所の共通定義。追加するときは `class="c-btn"` を付ければ同じ挙動になります

## 未対応

- **お問い合わせフォームの送信先が未設定**（`contact.html` の `<form action="">`）
- **プライバシーポリシーの事業者名が「HOKKAIDO 未来リーダーズ運営事務局」のみ**。
  運営法人名が決まったら `policy.html` の「事業者の氏名又は名称」に追記してください
- 記事ページは `?id=` 方式のため、各記事個別の OGP・description は静的には出力されません
- 画像は合計およそ 50MB。公開前に用途別のサイズ調整を推奨します
